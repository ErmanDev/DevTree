Install

Step-by-step setup for macOS, Linux and Windows. You install git and Rust, then build DevTree from source with one command.

Why build from source?

Ready-made downloads aren't published yet. Building takes a few minutes the first time. You get a single devtree program of about 3 MB that opens in its own window. It draws with the web engine your system already has, so there is no bundled browser.

Choose your system

⌘ macOS 🐧 Linux ⊞ Windows

macOS

Works on Apple Silicon and Intel Macs. Open the Terminal app and run the commands below.

1. Install git and the build tools

$ xcode-select --install

This installs Apple's Command Line Tools. They include git and the linker Rust needs. If it says they're already installed, go to the next step. If you use Homebrew, brew install git gives you a newer git as well.

2. Install Rust

$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Press Enter to accept the default install. Then open a new terminal window so the cargo command is found.

3. Build and install DevTree

$ git clone https://github.com/ErmanDev/DevTree.git
$ cd DevTree
$ cargo install --path .

This builds DevTree and puts it in ~/.cargo/bin, which Rust already added to your PATH.

4. Run it

$ devtree

The DevTree window opens. Close it (or press ⌘+Q) to quit. DevTree uses macOS's built-in WebKit, so there's nothing else to install.

Linux

Any recent 64-bit distribution works, on x86-64 or ARM.

1. Install git, a C compiler and WebKitGTK

Rust uses your system's C compiler to link programs, and DevTree's window is drawn by WebKitGTK. Pick your distribution:

# Debian, Ubuntu, Mint, Pop!_OS
$ sudo apt update && sudo apt install -y git curl build-essential libwebkit2gtk-4.1-dev libgtk-3-dev

# Fedora, RHEL, Rocky
$ sudo dnf install -y git curl gcc webkit2gtk4.1-devel gtk3-devel

# Arch, Manjaro
$ sudo pacman -S --needed git curl base-devel webkit2gtk-4.1 gtk3

On other distributions, install git, curl, a C compiler, and the development packages for WebKitGTK 4.1 and GTK 3.

2. Install Rust

$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
$ . "$HOME/.cargo/env"
Use rustup, not your distribution's Rust

DevTree needs Rust 1.85 or newer (the 2024 edition). The rustc/cargo packages of many distributions are older. rustup always installs the current version.

3. Build and install DevTree

$ git clone https://github.com/ErmanDev/DevTree.git
$ cd DevTree
$ cargo install --path .

DevTree is installed to ~/.cargo/bin/devtree, which is on your PATH after the step above.

4. Run it

$ devtree

The DevTree window opens. Close it to quit.

No desktop, or no WebKitGTK?

Build a browser-only DevTree with cargo install --path . --no-default-features. It doesn't need the WebKitGTK and GTK packages, and opens in your web browser instead. Any DevTree can also be started with devtree --browser.

Windows Subsystem for Linux (WSL)

The Linux steps work the same inside WSL 2. On Windows 11, the DevTree window appears on your Windows desktop. Otherwise, start it with devtree --no-open and open http://localhost:7878 in your Windows browser. WSL forwards localhost to Windows.

Use WSL for repositories stored inside WSL (under ~). For repositories on your Windows drive (/mnt/c/…), git is much faster if you install DevTree on Windows instead.

Windows

Works on Windows 10 and 11. Run the commands in PowerShell or Windows Terminal.

1. Install Git for Windows

PS> winget install --id Git.Git -e --source winget

Or download the installer from git-scm.com and keep the default options. It includes Git Credential Manager, which can save your GitHub sign-in.

2. Install Rust

Rust on Windows needs Microsoft's C++ build tools. The easiest way gets both:

  1. Download and run rustup-init.exe (64-bit) from rustup.rs.
  2. If it says the Visual Studio C++ build tools are missing, choose 1) Quick install via the Visual Studio Community installer and let it finish.
  3. Back in rustup, press Enter to accept the default install.

Prefer the command line? This does the same with winget:

PS> winget install --id Microsoft.VisualStudio.2022.BuildTools -e --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
PS> winget install --id Rustlang.Rustup -e

Then close and reopen your terminal so git and cargo are found.

3. Build and install DevTree

PS> git clone https://github.com/ErmanDev/DevTree.git
PS> cd DevTree
PS> cargo install --path .

DevTree is installed as %USERPROFILE%\.cargo\bin\devtree.exe, which rustup added to your PATH.

4. Run it

PS> devtree

The DevTree window opens. Close it to quit. You can also pin it to the taskbar, or start devtree.exe from File Explorer.

The window is drawn by Microsoft Edge WebView2, which comes with Windows 10 and 11. If DevTree says it's missing, install the WebView2 Runtime (the "Evergreen" version). If Windows Defender Firewall asks about DevTree, you can click Cancel: DevTree only accepts connections from your own computer.

Check it works

If something goes wrong, first check each tool is found and recent enough:

$ git --version      # 2.30 or newer
$ cargo --version    # 1.85 or newer
$ devtree --help     # shows DevTree's options

Then continue with your first repository.

Updating

Stop DevTree first (Ctrl+C), then in your DevTree folder:

$ git pull
$ cargo install --path . --force

Your list of imported repositories and your settings are kept.

Uninstalling

$ cargo uninstall devtree

Then delete DevTree's data folder, which only holds your list of imported repositories and the window's settings: ~/.devtree on macOS and Linux, %USERPROFILE%\.devtree on Windows. Your repositories themselves are never touched. If you installed Rust only for DevTree, rustup self uninstall removes it too.

Troubleshooting

"command not found: devtree" / "devtree is not recognized"

Your terminal was opened before Rust was installed. Open a new one. If it still fails, add ~/.cargo/bin (Windows: %USERPROFILE%\.cargo\bin) to your PATH.

"linker `cc` not found" (Linux)

The C compiler is missing. Install it with step 1 of the Linux instructions.

"linker `link.exe` not found" (Windows)

The Visual Studio C++ build tools are missing. Run the Microsoft.VisualStudio.2022.BuildTools command from step 2 of the Windows instructions, or add the Desktop development with C++ workload in the Visual Studio Installer.

"xcrun: error: invalid active developer path" (macOS)

A macOS update removed the Command Line Tools. Run xcode-select --install again.

"The system library `webkit2gtk-4.1` required by crate … was not found" (Linux)

The WebKitGTK development package is missing. Install it with step 1 of the Linux instructions, or build the browser-only version with --no-default-features.

The window opens but stays empty (Linux)

DevTree already turns off WebKitGTK's DMA-BUF renderer, the usual cause. If it still happens, try WEBKIT_DISABLE_COMPOSITING_MODE=1 devtree, or use devtree --browser.

"feature `edition2024` is required"

Your Rust is too old. If you installed it with rustup, run rustup update. If it came from your Linux distribution, remove that package and install Rust with rustup.

"Access is denied" while updating (Windows)

DevTree is still running, so Windows won't let cargo replace devtree.exe. Stop it and run the command again.

For problems after DevTree starts, see Getting started → Troubleshooting.
