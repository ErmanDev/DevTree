Updating

From version 0.1.2 on, DevTree checks for a new version each time it starts. On Windows, click Update now in the alert: DevTree downloads the new version, checks its SHA-256 checksum, replaces itself and restarts. Your repositories and settings are kept. On macOS and Linux, the alert links here; update a source build as described in the install guide.

On 0.1.1 or older? Download the new version above and replace your old devtree-windows-x64.exe with it, once. Updates install themselves after that.
